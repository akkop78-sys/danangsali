# 다낭살이 쇼핑몰 (다낭팬티)

베트남 다낭에서 고른 속옷(**다낭팬티**)을 소개하고, 주문을 받고, 네이버·쿠팡에 올릴 CSV까지 받을 수 있는 **초보용 자사몰**입니다.

지금 결제는 **연습(데모) 주문**입니다. 실제 카드 결제는 되지 않으며, 나중에 토스페이먼츠를 붙일 자리만 준비되어 있습니다.

## 1. 실행 방법 (초보)

1. 이 폴더에서 터미널(명령 프롬프트)을 엽니다.
2. 아래를 입력합니다.

```bash
pip install -r requirements.txt
python shop.py
```

3. 브라우저에서 엽니다.

- 쇼핑몰: http://127.0.0.1:5000
- 관리자: http://127.0.0.1:5000/admin/login

### 관리자 처음 로그인

| 항목 | 값 |
|------|-----|
| 아이디 | `admin` |
| 비밀번호 | `tokkiyasa123` |

로그인 후 **비밀번호** 메뉴에서 꼭 바꿔 주세요.

## 2. 판매자가 할 일 (순서)

1. 관리자 로그인
2. **상품**에서 내 옷 등록 (사진, 가격, 재고, 사이즈)
3. 손님은 **회원가입 → 장바구니 → 연습 주문**
4. 관리자 **주문**에서 상태 변경 (접수 → 배송준비 → 배송중 → 완료)
5. **마켓 내보내기**에서 네이버/쿠팡 CSV 다운로드
6. **따라하기**를 보며 스마트스토어·쿠팡 윙에 업로드

## 3. 네이버·쿠팡에 올리기

계정·사업자가 아직 없어도 CSV는 받을 수 있습니다.  
가입 후 공식 양식에 값을 복사해 올리면 됩니다.

- 스마트스토어: https://sell.smartstore.naver.com
- 쿠팡 윙: https://wing.coupang.com

자세한 단계는 관리자 화면의 **따라하기**에 있습니다.

## 4. 나중에 진짜 결제 (토스페이먼츠)

1. 토스페이먼츠 가맹 계약 후 키를 받습니다.
2. 환경변수로 넣습니다.

```bash
set TOSS_CLIENT_KEY=발급받은_클라이언트키
set TOSS_SECRET_KEY=발급받은_시크릿키
set PAYMENT_MODE=toss
```

3. `payments.py`의 `confirm_payment`에 토스 승인 API를 연결하면 됩니다.  
   지금은 `PAYMENT_MODE=demo`가 기본입니다.

## 5. 폴더 안내

| 파일/폴더 | 역할 |
|-----------|------|
| `shop.py` | 쇼핑몰 실행 진입점 |
| `admin_routes.py` | 관리자 기능 |
| `models.py` | 회원·상품·주문 DB |
| `export.py` | 네이버/쿠팡 CSV |
| `payments.py` | 결제 준비(스텁) |
| `tokkiyasa.db` | 실행 후 생기는 데이터 파일 |
| `static/uploads/` | 올린 상품 사진 |

## 6. 주의

- 이 프로그램은 **내 컴퓨터에서 연습·운영 준비**용입니다.
- 인터넷에 공개하려면 별도 서버(클라우드) 배포가 필요합니다.
- 네이버/쿠팡 **API 자동 등록**은 판매자 키가 생긴 뒤 다음 단계에서 가능합니다.
