네이버·쿠팡 따라하기

완전히 초보 기준으로 적어 두었어요. 위에서부터 천천히 하세요.

0. 먼저 알아둘 것

  • 네이버·쿠팡에 물건을 팔려면 보통 사업자등록이 필요합니다. (통신판매업 신고도 함께 안내됩니다.)
  • 홈택스에서 사업자등록을 하거나, 세무서/인터넷으로 신청할 수 있어요.
  • 이 프로그램은 계정 없이도 CSV 파일을 만들어 줍니다. 계정 가입 후 그 파일을 올리면 됩니다.

1. 다낭살이에 내 물건 등록

  1. 상품 관리에서 내 옷을 등록합니다. (사진, 가격, 재고, 사이즈)
  2. 등록이 끝나면 마켓 내보내기에서 CSV를 받습니다.

2. 네이버 스마트스토어에 올리기

  1. 스마트스토어 센터에 가입합니다.
  2. 판매자 정보·정산 계좌·사업자 정보를 입력합니다.
  3. 상품 > 상품 등록 / 대량등록 메뉴로 갑니다.
  4. 네이버가 제공하는 공식 엑셀(또는 CSV) 양식을 다운로드합니다.
  5. 다낭살이에서 받은 tokkiyasa_naver.csv를 엑셀로 엽니다.
  6. 상품명, 판매가, 재고, 설명, 이미지, 옵션(사이즈) 값을 공식 양식의 같은 의미 칸에 복사합니다.
  7. 공식 양식을 스마트스토어에 업로드합니다.

3. 쿠팡에 올리기

  1. 쿠팡 윙에 판매자 가입합니다.
  2. 판매자 승인·카테고리·출고지 설정을 마칩니다.
  3. 상품 대량등록(또는 엑셀 등록) 메뉴에서 공식 양식을 받습니다.
  4. 다낭살이 tokkiyasa_coupang.csv의 내용을 공식 양식에 복사합니다.
  5. 업로드 후 승인/노출 상태를 확인합니다.

4. 양식이 바뀌었을 때

네이버·쿠팡은 가끔 열 이름을 바꿉니다. 그때는 공식 양식을 새로 받은 뒤, 다낭살이 CSV의 값을 “이름만 비슷한 열”에 옮겨 붙이면 됩니다. 상품 데이터 원본은 항상 다낭살이 관리자에 두면 두 채널에 다시 내보내기 쉽습니다.

5. 나중에 자동 연동하려면

스마트스토어 API / 쿠팡 Open API 키가 생기면, 그때 자동 업로드를 붙일 수 있습니다. 지금은 초보에게 가장 안전한 방법인 파일 내보내기 + 공식 업로드를 씁니다.
